# CampusBite – College Canteen

This is the single-file HTML version of your CampusBite website. CSS and JavaScript are included inside `index.html`.

## Publish with GitHub Pages (phone-friendly steps)
1. Sign in to https://github.com/
2. Create a **Public** repository named `CampusBite`.
3. Open the repository, choose **Add file → Upload files**.
4. Upload `index.html` (not the ZIP itself). Commit the changes.
5. Open **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will look like `https://YOUR-USERNAME.github.io/CampusBite/`.

The final URL is not active until you publish from your own GitHub account.
